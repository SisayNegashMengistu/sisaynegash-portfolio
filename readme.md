# 🌐 Portifolio

Welcome to my interactive portfolio website! This site showcases my skills, projects, and contact information through a smooth and modern interface using Three.js, Framer Motion, and TailwindCSS.

---

## 🚀 Features

- Modern and responsive UI design
- 3D interactive elements with [Three.js](https://threejs.org/)
- Filterable project showcase with smooth animations
- Mobile and dark mode friendly
- Live demo and GitHub links for each project
- Dynamic category filtering with animation
- Smooth transitions using Framer Motion

---

## Tech Stack

- **Frontend:** React, TypeScript
- **Styling:** TailwindCSS
- **Animations:** Framer Motion
- **3D Graphics:** Three.js / @react-three/fiber
- **Icons:** Lucide Icons
- **State Management:** useState, Zustand
- **Deployment:** Vercel

---

## Folder Structure

```

src/
├── assets/            # Static images and icons
├── components/        # UI Components (Navbar, Footer, ProjectCard, etc.)
├── data/              # Project data and categories
├── pages/             # Page structure (Home, About, Projects, etc.)
├── styles/            # Global styles
├── App.tsx
└── main.tsx

```

---

## Setup & Installation

1. **Clone the repository:**

```bash
git clone https://github.com/SisayNegashMengistu/sisay.git
```

2. **Install dependencies:**

```bash
npm install
```

3. **Run the development server:**

```bash
npm run dev
```

4. **Build for production:**

```bash
npm run build
```

## 🧠 Project Structure Highlights

- Projects are managed dynamically from a single file: `src/data/portfolioData.ts`
- Images can be imported from the `assets` folder or linked via CDN
- Animations are controlled with Framer Motion's `AnimatePresence` and `motion.div`
- Includes a category filter with layout-preserving animations
